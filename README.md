# ArgpiSuiteNPP
*ArgpiSuiteNPP** is a Notepad++ plugin. It main feature is: Format code, Encrypt/Decrypt, Encode/Decode, Password Generator, UUID/GUID &amp; ULID Generator, Hashing, JWT Decoder, SON / XML / SQL Path Querying, CSV / TSV Column Alignment &amp; Filtering, Smart Deduplication &amp; Sorting and many others features in the future.
